# Report an issue

Search [existing issues](https://github.com/IOFabrik/IOFabrik-CE/issues) before opening a new one. If an issue already covers your report, add relevant details there.

For security vulnerabilities, follow the [security policy](SECURITY.md) instead of opening a public issue.

## Report a bug

Open a [new issue](https://github.com/IOFabrik/IOFabrik-CE/issues/new) with a title that describes the problem. Include:

- Your IOFabrik CE version and operating system.
- Steps to reproduce the problem.
- What you expected to happen and what happened instead.
- Relevant error messages, logs, or screenshots.

Remove credentials, customer project data, and other confidential information from examples and attachments.

## Request a feature

Open a [new issue](https://github.com/IOFabrik/IOFabrik-CE/issues/new) that describes the problem you want to solve and how the proposed feature would help. Include an example of your workflow.
