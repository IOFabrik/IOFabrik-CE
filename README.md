# IOFabrik CE

## Introduction

IOFabrik Community Edition is a desktop Git client for industrial automation teams. Track PLC and HMI project revisions, compare changes, and sync with your team without using the command line.

Keep using your engineering software to edit PLC and HMI projects. IOFabrik CE tracks the revisions and helps you review changes.

## Features

- Save project revisions and browse previous versions.
- Compare ladder logic (`.l5x`), electrical drawing PDFs, images, and text files.
- Review and resolve conflicting changes with a guided workflow.
- Work locally, or connect to GitHub to share and sync with your team.

Visual comparisons are available for supported file formats, not every project file.

## Get started

Read the [IOFabrik documentation](https://iofabrik.com/docs/) for installation instructions and guides to your first project.
